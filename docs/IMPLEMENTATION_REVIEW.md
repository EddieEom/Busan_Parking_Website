# 첨부 개발 문서와 구현 대조

검토일: 2026-10-15. 문서 8개의 본문·표·머리말·꼬리말과 삽입 이미지, 별도 개발 방향 이미지를 검토했습니다. V2·V3에 반복 수록된 V1 내용은 텍스트 차이도 비교했습니다. 이 파일은 과거 문서의 완료 기록과 현재 저장소에서 확인한 구현·검증을 구분합니다.

## 적용 기준

- V1 → V2 → V3 → V4 지도 → V5 PWA → V6 MCP/AI를 발전 순서로 사용합니다. 초기 문서나 방향 이미지에 쓰인 이전 버전 번호가 최신 단계의 기능을 되돌리는 기준은 아닙니다.
- 문서의 `new-busan-parking`, `mcp/src/*.ts`, 과거 배포 주소는 당시 구현 예시입니다. 현재 저장소의 JavaScript ES Modules, `mcp-server/`, `services/`, Pages Functions를 유지합니다.
- 문서의 핵심인 기존 통합 API 재사용과 AI용 도구 계층 확장을 반영합니다. 현재 웹의 OpenRouter를 유지하며, 문서의 향후 Gemini 예시 때문에 검증된 연결을 교체하지 않습니다. Gemini 진단 CLI는 유지합니다.
- 50개·615개·44개 매칭·특정 시점의 잔여 대수는 과거 관측값입니다. 현재 결과나 통과 조건으로 고정하지 않습니다.

## 변경 파일과 데이터 흐름

- `services/parkingService.js`: 빈자리순 기능, 이름 상세조회·후보 응답, 주차대수·매칭 정보.
- `mcp-server/createServer.js`: 새 도구 등록과 상세 입력 스키마 확장. 기존 비교·id 상세 계약 유지.
- `mcp-server/openrouterClient.js`: 네 도구 중 요청에 맞는 선택, 검증된 카드 결과·경고 전달, 후보 임의 확정 및 후속 조회 실패 처리.
- `mcp-server/geminiClient.js`: 진단 CLI의 도구 허용 목록·검증도 네 도구와 이름 후보에 맞춤.
- `functions/api/chat.js`: 기존 응답에 parkings·조회 시각·선택 필요 여부·일치 수 추가.
- `parking-card.js`, `app.js`, `chat.js`, `index.html`, `style.css`: 기존 목록 카드를 공유하고 AI 결과에도 표시. 1분마다 지연 현황 재평가.
- `lib/normalizeName.js`, `lib/mergeParkingData.js`: 문서에 명시된 화명역 별칭 및 충돌 보류.
- `service-worker.js`: 새 정적 모듈 캐시·버전 변경. `.dev.vars.example`: 같은 사이트 MCP를 기본으로 사용.
- 테스트·README·MCP_README: 추가 계약과 실행 방법 반영.

흐름은 `사용자 → 웹 AI → OpenRouter → MCP SDK → 도구 → 기존 통합 API 로직 → 공공데이터`입니다. AI 카드의 값은 모델이 만든 JSON이 아니라 검증된 MCP 결과를 사용합니다. DB·데이터 마이그레이션은 없으며, 실제 환경변수·키 파일은 수정하지 않습니다.

## 검증 및 남은 확인

최종 자동 테스트: 83개 통과, 실패·건너뜀 0개. 수정 전 기준은 70개 통과였습니다. `git diff --check`도 통과했습니다.

자동 테스트 명령:

```powershell
node --test scripts/*.test.mjs mcp-server/test/*.test.js
```

서비스 정렬·제한·누락값, 정확한 이름·중복 후보·잘못된 입력, stdio/HTTP 실제 프로토콜, Inspector CLI, AI 선택·결과 연결·경고·후속 실패, 웹 모듈의 설명/카드 표시·오류 시 이전 카드 제거·일반 검색 상태 유지, PWA 정적 의존성을 검증합니다. 웹 모듈 테스트의 모델·네트워크·DOM은 테스트 대역을 사용하며 실제 브라우저 렌더링과 구분합니다.

다음 사항은 구현 완료와 별도로 확인해야 합니다.

- 실제 공공데이터: 로컬 키를 사용한 통합 API 호출은 502를 반환했습니다. 세 원천 조회가 실패했으며 키·승인·호출 한도·실행 환경 네트워크 중 원인은 이 결과만으로 확정할 수 없습니다.
- 문서에 나열된 나머지 4개 별칭(부산기계공고 후문, 롯데 광복점 뒤(2), 대연고가밑, 만덕2동사앞복개): 대응 기본정보의 정확한 이름·주소가 문서 본문에 없고 현재 실데이터 조회도 실패하여 매핑을 추측하지 않았습니다. 실제 원본 대조 후 추가해야 합니다. 매칭표 50/615/44 수치를 현재 상태로 재현했다고 주장하지 않습니다.
- 실제 OpenRouter·Gemini 호출, Turnstile 통과, 배포된 MCP 연결: 이 변경의 자동 테스트만으로 확인되지 않습니다. 유료 모델 실호출·배포·계정 설정 변경은 수행하지 않았습니다.
- 실제 브라우저 및 모바일 설치: 브라우저 도구 연결이 실행 환경 오류로 실패했습니다. Android/iPhone/PC의 설치·오프라인·지도 새 창·새 버전 갱신은 실제 기기에서 확인해야 합니다.
- Functions 배포 번들: 로컬 Wrangler가 설치되어 있지 않고 실행 확인도 완료하지 못했습니다. 배포 환경에서 npm 의존성 설치와 Functions 빌드를 확인해야 합니다.
- ChatGPT·Claude 등 외부 클라이언트: 기존 stdio/HTTP MCP 인터페이스를 제공하지만 각 제품 계정에 등록하거나 실사용을 검증하지 않았습니다. 별도 제품 연결 절차는 각 클라이언트의 현재 지원 범위에 따라 설정해야 합니다.
- 좌표 기반 거리 추천·현재 영업 판정·RAG·Flutter·Resource/Prompt는 문서의 장기 확장 예시입니다. 검증된 좌표·요금 규정 등 필요한 기반 없이 새 기능으로 단정하지 않습니다.

외부 연동이 가능한 환경에서는 `search_parking → find_available_parking → get_parking_detail(name/id) → compare_parkings`, 자연어 세 유형(일반 검색·빈자리순·요금/운영시간), 중복 이름의 지역 재질문, 일반 검색과 AI 카드의 갱신 시각·지도 검색어, 실제 PWA 설치·업데이트를 순서대로 확인합니다.
