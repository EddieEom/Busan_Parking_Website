## 첨부 화면의 좌표 오류

‘기본정보 API 조회 실패’와 ‘좌표 없음’이 같이 나온 화면입니다. 현재 위치 권한 실패와는 다릅니다.

V8.2에서 기본정보 1000건 단위 수집, 일시 오류 재시도, 서버 기본정보 저장본(15분 재사용·실패 시 최대 24시간) 처리를 추가했습니다. 저장본을 쓰면 원본 수신 시각과 경고를 표시합니다. 유효한 키/활용승인이 없거나 정상 저장본이 없으면 좌표를 만들어내지 않습니다.

V8.3에서는 GPS 클릭 시 좌표 데이터가 없으면 한 번 자동 재조회하고, 계속 없으면 원인 안내 및 ‘좌표 정보 다시 불러오기’ 버튼을 제공합니다. 재조회할 때 사용자 위치를 유지합니다.

## 구현상 차이

- 참고 사이트는 실시간 대상 중심으로 반환하지만 현재 프로젝트는 기본정보만 있는 주차장도 계속 제공합니다. 기본정보만 있는 곳을 실시간 주차 가능으로 표시하지 않습니다.
- 참고 코드의 중복 이름 첫 항목 선택 방식은 따르지 않았습니다. 동명/중복 후보는 확인 대상으로 남겨 잘못된 위치·요금 결합을 방지합니다.
- ‘화명역 근처’ 같은 문장은 이름·주소 검색으로 처리하고 거리 기반 결과라고 주장하지 않습니다. 현재 위치 기반 거리는 GPS 경로에서만 계산합니다.
- 사용자 좌표는 기기 메모리 안에서만 사용합니다. 서버 기본정보 캐시에는 공공 주차장 정보만 들어갑니다.

## 검증

Node 자동 테스트: API 페이지 수집·재시도·기본정보 캐시/장애 복구, 별칭 및 중복 연결 보류, 좌표 형식, 주소 검색, 빠른 정렬·Enter/한글 입력, GPS 복구·음성·PWA 회귀 검증.
Chromium: 모바일/데스크톱에서 검색→GPS→정렬→새로고침→음성 연결 및 Service Worker 오프라인 동작을 테스트 대역 데이터로 확인합니다. 실제 휴대폰 음성·GPS 하드웨어는 별도 확인 대상입니다.

최종 자동 테스트 118개 통과, Cloudflare Pages Functions 빌드 성공. 브라우저에서 기본정보 실패 후 자동 재조회 및 수동 재시도로 위치를 유지한 채 GPS 5곳을 복구하는 흐름까지 확인했습니다.
