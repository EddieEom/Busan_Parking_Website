# 문서와 구현 대조

첨부된 V1~V8 개발 설명서를 기준으로 기존 `main`(99cd939)을 대조했습니다. 설명서의 과거 테스트 수치(주차장 수·빈자리 수)는 실시간 값이므로 하드코딩하지 않습니다. 초기 로드맵 이미지보다 상세 버전 문서의 최종 흐름을 기준으로 합니다.

| 단계 | 기존 상태 / 보완 | 구현 위치 |
| --- | --- | --- |
| V1~V3 | 3개 공공 API 통합, 모듈 분리, 검색 정규화·관련도·빈자리 정렬·새로고침 유지 | `lib/`, `functions/api/parking.js`, `app.js` |
| V4 | 원본 주소와 품질 안내, 부산+이름 카카오맵 검색 유지 | `parking-card.js` |
| V5 | 설치 UI, 정적 캐시, API 비캐시, 자동 업데이트 유지 | manifest, `pwa.js`, `service-worker.js` |
| V6.0~V6.2 | AI UI 및 MCP 3종+비교 도구 유지. 상세조회 일반 접미사 정규화 보완 | `mcp-server/`, `services/parkingService.js` |
| V6.3 | Remote MCP 의존 없이 Gemini가 JSON 조건만 반환하는 서버 경로 추가. GET 상태 확인·검증된 POST 연결 테스트 | `services/parkingIntent.js`, `functions/api/ai-test.js` |
| V6.4.1 | 로컬 규칙 우선, 최소 빈자리·개수·상세·후보·무관 질문·빈 결과 처리. Gemini 429/503 최대 2회 재시도. 실제 데이터로만 결과 생성 | `functions/api/ai-parking.js`, `services/intentSearch.js`, `chat.js` |

## 서버 설정

- 필수: 기존 `DATA_API_KEY` (다른 키를 쓰는 기본정보 API는 `BASIC_API_KEY`).
- 기본 자연어 검색: 추가 AI 설정 없이 동작합니다.
- 복잡한 자연어를 Gemini가 해석하도록 하려면 `GEMINI_API_KEY`, 선택적으로 `GEMINI_INTENT_MODEL`을 설정합니다.
- 유료 외부 호출은 기존 `TURNSTILE_SITE_KEY`, `TURNSTILE_SECRET_KEY` 사용자 확인 후 실행합니다.
- Gemini 키가 없고 기존 OpenRouter와 Turnstile이 구성되어 있으면 복잡한 요청은 기존 `/api/chat` → OpenRouter → MCP 경로를 사용합니다. 기존 MCP/비교 기능을 삭제하지 않았습니다.
- 키가 모두 없으면 기본 자연어 검색은 동작하고 복잡한 요청에는 다시 질문하도록 안내합니다.
- `/api/ai-parking` GET의 `version` 값은 `V6.4.1-hybrid-local-first`입니다.
- `/api/ai-test` GET은 키 구성 상태만 반환합니다. 키와 사용자 확인 없이는 과금 요청을 실행하지 않습니다. POST는 `question`, `turnstileToken`, 같은 출처의 Origin이 필요합니다.

## 검증 방법

```bash
npm ci
npm --prefix mcp-server ci
npm test
```

테스트는 가짜 AI·주차장 API 응답과 실제 MCP 프로토콜을 사용합니다. 실제 공공데이터·AI 키나 사용자의 브라우저 권한이 필요한 배포 검증은 자동 테스트 성공과 구분합니다. 실제 키는 저장소에 추가하지 않습니다.

## V7.0 GPS

- `geolocation.js`: 기본정보 `raw.basic.xCdnt`(위도), `yCdnt`(경도) 사용. 빈값/비숫자/범위 오류/0,0 제외, 위경도가 뒤집힌 경우 보정.
- 사용자 좌표는 브라우저 메모리에서만 사용하며 서버·AI·localStorage에 전송/저장하지 않습니다.
- GPS 버튼을 누를 때만 위치 권한 요청. 고정밀·12초 타임아웃·60초 캐시.
- Haversine 직선거리로 가장 가까운 5곳을 먼저 선택. 그 5곳에서 빈자리순/요금순/필터 적용.
- 새로고침은 마지막 GPS 위치를 유지해 새 데이터로 거리 재계산. 검색어 입력/초기화는 위치 모드 종료.
- 좌표 없는 데이터, 권한 거부, 위치 확인 불가, 시간초과 안내. 가장 가까운 곳이 50km 초과면 부산 범위 경고.
- 카드에 m/km 거리 표시, 기존 부산+주차장명 카카오맵 링크 유지. 도로 거리·소요시간을 추정하지 않습니다.

## V8.0 / V8.1 음성 입력

- `voice.js`는 `SpeechRecognition` 또는 `webkitSpeechRecognition`을 사용합니다. `ko-KR`, `continuous=false`, `interimResults=false`, `maxAlternatives=1`.
- 버튼을 눌러야 인식을 시작하며 다시 누르면 취소합니다. 최종 문장을 입력창에 보여주고 기존 보내기 동작을 실행합니다.
- “내 주변/내 근처/현재 위치/가까운 주차장”은 AI 없이 V7 GPS 실행. 빈자리·여유·주차 가능 표현은 주변 5곳을 빈자리순으로 정렬합니다.
- “화명역 근처”처럼 장소가 명시된 문장을 현재 위치로 잘못 바꾸지 않고 일반 자연어 검색에 전달합니다.
- 듣는 중 빨간 버튼·상태문·애니메이션, 오류별 한국어 안내. 음성 미지원·권한 거부 시 텍스트와 GPS는 계속 사용할 수 있습니다.
- 오디오 녹음 파일을 생성하거나 앱 서버에 업로드하지 않습니다. 브라우저 음성 인식 서비스 자체는 브라우저 제공자의 서버를 사용할 수 있으며 오프라인 음성 인식을 보장하지 않습니다.
- `v8.css`는 모바일에서 보내기와 58px 마이크 버튼을 같은 줄에 고정합니다. 모션 감소 환경에서는 pulse 애니메이션을 끕니다.
- PWA 자동 업데이트가 음성 인식·GPS 권한 요청 중 화면을 다시 로드하지 않도록 보호합니다.

## 배포 후 실제 기기 확인

1. `/api/ai-parking`에서 버전 문자열을 확인합니다.
2. “화명 주차장 찾아줘”, “빈자리 10대 이상인 곳 3개만 찾아줘”, “화명역 요금과 운영시간 알려줘” 검색 및 카드 확인.
3. GPS 허용 후 최대 5곳·거리 배지·빈자리순·새로고침 위치 유지 확인. 권한 거부 안내도 확인.
4. 마이크 허용 후 일반 발화와 “내 주변에서 빈자리 많은 주차장 찾아줘” 확인. 권한 거부·무음·지원하지 않는 브라우저도 확인.
5. 모바일에서 보내기·마이크가 같은 줄인지, 카카오맵이 새 창에서 열리는지 확인.
6. 설치된 앱을 다시 열어 V8 정적 파일을 받는지 확인. API 응답은 캐시하지 않습니다.

자동 테스트는 실제 휴대폰의 위치·마이크 권한과 외부 AI의 유효 키/잔액/모델 접근 권한을 대신 검증하지 않습니다.

## 최종 검증 기록

- Node 자동 테스트: 검색·데이터 정합성·MCP 프로토콜·외부 호출 보호·의도 해석·GPS·음성·PWA 갱신을 검증합니다.
- Chromium 브라우저: 데스크톱 및 390px 모바일에서 로컬 자연어 API, GPS 5곳, 빈자리 정렬, 새로고침 위치 유지, 음성 인식 결과→GPS 연결, 58px 마이크·보내기 같은 줄, 가로 넘침 없음 및 JS 오류 없음을 확인했습니다. 위치와 음성 인식 결과는 테스트 대역을 주입했습니다.
- 기존 요금 비교: OpenRouter가 구성되어 있으면 Gemini 키 유무와 관계없이 기존 사용자 확인→OpenRouter→MCP 비교 경로를 유지합니다.
- 최종 자동 테스트 **105개 통과**. Cloudflare Wrangler Pages Functions 빌드도 성공했습니다.
- 실제 Service Worker를 등록한 Chromium에서도 V8 캐시의 새 모듈(음성/GPS)을 확인했습니다. API가 캐시에 없고, 오프라인 재접속 시 앱 화면만 복원되며 과거 빈자리가 표시되지 않는 것을 확인했습니다.
